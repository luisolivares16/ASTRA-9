# ASTRA-9 Security Terminal
ASTRA-9 is a Python-based security terminal simulation that I created as my capstone project strictly using Python fundamentals. 
The program simulates an access-control system, evaluating the user's mission performance, accuracy, penalties, and energy level to generate a security status and access report.
## Features
- Callsign validation
- Mission performance scoring
- Accuracy and penalty evaluation
- Security tier calculation
- Energy diagnostics
- Caesar cipher encryption and decryption
- Access status classification
- Priority access determination
## Python Concepts Used
- Functions and parameters
- Conditional statements
- Loops 
- String manipulation
- Lists and tuples
- Arithmetic and assignment operators
- User input and type conversion
- Built-in Python functions
## How to Run
1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Run the program using python "ASTRA-9 Capstone Project.py"
4. Follow the prompts in the terminal.
